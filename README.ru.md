# Local Dictation

[English (canonical)](README.md) · [Español](README.es.md) · [Русский](README.ru.md)

Локальная диктовка для macOS, настроенная и проверенная для русского языка. Удерживайте горячую клавишу, говорите, и сырой транскрипт Whisper попадёт прямо в активное текстовое поле — без облака, постобработки и нажатия Enter.

Аудио и распознавание остаются на вашем Mac: приложение запускает WhisperKit локально. Декодер настроен на `language = ru`. Другие языки не прошли приёмочный gate проекта и не входят в claims `v0.1.0`. Веса модели и файлы tokenizer не включены в репозиторий; вы устанавливаете их самостоятельно в offline-режиме.

Перед диктовкой локальной сборке нужны разрешения на микрофон и Универсальный доступ. Выдайте их через приложение в строке меню до проверки вставки.

Эта экспериментальная source-only alpha рассчитана на macOS 14 и новее. Текущая автоматическая проверка сборки выполняется на macOS 15; runtime-совместимость с macOS 14 отдельно ещё не проверялась. В ней нет телеметрии, сервиса обновлений и `.app` для скачивания. Перед использованием прочитайте документы о [приватности](docs/PRIVACY.md), [сборке](docs/BUILD.md) и [известных ограничениях](docs/LIMITATIONS.md).

При расхождениях в формулировках канонической считается английская версия.

## Что делает приложение

- Приложение для строки меню, написанное на Swift и AppKit.
- Hold-to-talk с настраиваемой глобальной горячей клавишей.
- Один локальный inference-проход WhisperKit (`language = ru`).
- Побайтово неизменная вставка сырого транскрипта — без модели очистки, словаря, истории и голосовых команд.
- Вставка через Accessibility API с защищённым fallback Command+V; Enter/Return никогда не синтезируется.
- Временное аудио удаляется до продолжения распознавания.

Hands-free по двойному нажатию существует в исходном коде, но остаётся экспериментальным и не входит в release claim.

## Что не входит

- Файлы модели и tokenizer — offline-установка описана в [MODEL_SETUP.md](docs/MODEL_SETUP.md).
- Подписанный или нотаризованный `.app`.
- Облачное распознавание, аналитика, телеметрия и сервис обновлений.
- Гарантированная совместимость с Bluetooth, WhatsApp или любым целевым приложением.
- Проверенная поддержка английского, испанского или автоматического определения языка.

## Статус

`v0.1.0` — source-only alpha под [лицензией MIT](LICENSE). Revisions модели и tokenizer привязаны к точным commit revisions и снабжены полными integrity inventories, но сами внешние файлы не включены в проект и не лицензируются им.

## Быстрая проверка

```bash
./scripts/privacy-scan.sh
./scripts/check-dependencies.sh
./scripts/check-toolchain.sh
./scripts/run-core-tests-offline.sh
./scripts/run-tests.sh
```

Приложение никогда не скачивает модель во время runtime. Граница offline-установки описана в [MODEL_SETUP.md](docs/MODEL_SETUP.md).
