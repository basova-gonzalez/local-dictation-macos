# Security policy

Please do not include real dictated text, recordings, clipboard contents, user paths, hardware identifiers, credentials, or screenshots containing private content in a report.

After publication, use the repository's private GitHub Security Advisory form for vulnerabilities. Until that channel exists, do not open a public issue containing sensitive security details.

Reports should contain only the affected version, operating-system version, content-free failure stage, reproduction structure, and expected versus observed behavior.

Local Dictation intentionally does not create diagnostic logs. Choose the first failing stage from visible application behavior and describe only the sequence of actions and state transitions. Do not attach system logs if they expose private content or user paths.
